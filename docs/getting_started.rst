Getting Started
===============

The purpose of this guide is to illustrate some of the main features that ``ClinicaDL`` provides.
It assumes a basic working knowledge of neuroimaging and Deep Learning.

``ClinicaDL`` is an open source Python library to **train** and **evaluate** Deep Learning models on
neuroimaging data. It also provides useful tools to **manipulate your data**
(e.g. transforms, split, patch extraction). 

``ClinicaDL`` puts a strong emphasis **experiment management** and **reproducibility**, which makes it a useful tool for 
**benchmarking**.

As part of the PyTorch eco-system, ``ClinicaDL`` is compatible with other community tools
(e.g. :monai:`MONAI <>`, :torchio:`TorchIO <>`).
